# PackSound

Ecualizador y efectos de audio para Android (Kotlin).

## Generar el APK
1. Instala Android Studio: https://developer.android.com/studio
2. File > Open > elige la carpeta PackSound y espera a que termine "Gradle Sync".
3. Menú Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Cuando termine, clic en "locate": el archivo queda en app/build/outputs/apk/debug/app-debug.apk
5. Pásalo a tu celular e instálalo (permite "instalar apps desconocidas").
